API 토큰 입력

이 대시보드는 GAS API 토큰이 있어야 데이터를 조회할 수 있습니다. 토큰은 이 브라우저의 localStorage에만 저장되며 서버나 소스코드에 남지 않습니다.

아직 토큰을 만든 적이 없다면 “최초 발급받기”를 누르세요. 이미 발급된 경우에는 already_initialized 가 반환되며, 기존 토큰을 그대로 입력해야 합니다.
